doz 0.52.20

A space's live state, its file from the dashboard, and a record of each run.

  • doz workspace state W shows a space's state as this Mac sees it: each agent, sandbox, folder, room and member the

file declares, whether it is there, what it is doing, what has drifted from the file, and what needs you (an agent waiting on a permission, a sandbox that failed). Looking never starts the daemon; with it stopped, things read as not known.

  • The dashboard can read a workspace's space file, check it (the same plan doz workspace plan prints) and save it.

A save is refused if the file changed since it was opened, never runs up, and is made only in this Mac's own browser; another computer reads the file only when chat is shared with it. doz workspace show W --space and doz workspace edit W --space-file F --if-match SHA do the same in a terminal.

  • While a space runs, Dozable records its state each time it changes, kept with the run and checked in its archive.

doz workspace runs W --frames RUN lists them; a run from before this version has only its last state.

  • The visual editor itself comes in a later version.
