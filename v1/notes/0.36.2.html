doz nuke and doz inventory: start over without reinstalling (issue #276; owner 2026-10-19: "remove everything back to a fresh install, doz stays installed ; dry run with --dry-run ; lists everything and their sizes and location with a prompt to confirm by default", and "a doz inventory command that lists everything (same that nuke shows; just for information only)"). Canary: stable moves on the owner's promote.

  • doz nuke lists everything Dozable keeps on this Mac, each item with its place and size, then asks once, and removes it: the store, the settings folder, the download cache (~/Library/Caches/dozer-sandbox) and the keychain items Dozable made (accounts' keys, the default GitHub key; never another doz-* item). doz stays installed; the next command is a first run. --dry-run lists and removes nothing; --yes skips the question. A running host is stopped first; a running doz ui or doz serve refuses it.
  • Never touched: workspace folders, the Mac's own Claude Code and Codex logins, Apple's container data.
  • doz inventory prints the same list and changes nothing.
  • Test safety: a guarded test run gets an in-memory keychain and a cache only from DOZ_TEST_CACHE_DIR — the first version, run guarded, still listed this Mac's real cache.
  • Docs: the manual's "Start over: doz nuke" section and troubleshooting row, the CLI reference.
  • Tests: make test 1120 tests, 0 failures, 4 skipped (new: NukeTests); make docs-drift-check green; a real nuke --yes on a scratch store removed exactly its three items.
