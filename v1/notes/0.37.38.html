0.37.x fixes (issue #373, the rolling umbrella for small fixes to 0.37). Owner 2026-11-02: "make the update period daily (not hourly)", then "ship both".

  • The recipe catalogue check is daily, not hourly: while its host runs, doz looks at doz.sh for a newer signed recipe catalogue at most once a day, and each community catalogue you added the same. The last look is remembered, so a host restart does not ask again early, and the host still checks hourly whether a look is due (a host started near the end of the day does not wait almost two). The signing explainer and the manual's recipe pages say so.
  • Tests: the catalogue unit tests (16, now with a look 23 hours later still not due), the community recipe tests (18), the catalogue end to end (32/32), the docs checks, and CI's full run.
