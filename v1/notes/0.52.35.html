doz 0.52.35

Every workspace now has a document: doz workspace doc W prints it — the space file it was made from, or one generated from the record of a workspace made with the wizard or doz workspace new — with --json (kind: Document, always with its lifetime) and --write FILE to save it as a space file. The document never holds a secret value, a grant or the lifecycle phase. Space files can carry the coming format keys under x-dozable (a text brief, lifetime, the main folder); with a brief there, the top-level brief: is no longer needed. In a guarded test run, ~ in a space file now means the test's home.
