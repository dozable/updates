doz 0.34.0

Dozer's AI Kitchen, phase 1: try 42 coding agents and AI tools in one command, on a key from any major provider (issue #251; owner 2026-10-15: "before 0.34, get it done and test and then /ship"). Canary: stable moves on the owner's promote.

  • doz try: a throwaway sandbox for any supported tool, started and entered in one command. It gets its own empty folder, a network that reaches its model and nothing else, and the user's key for its provider. On leaving it asks: sleep, delete or keep. Also --rm, --keep, -d and --dry-run.
  • Quick try in the dashboard: a full-page window with search, kind and category filters, and cards or a list. Try now opens a setup step for the model, key and folder. It opens at once, with the catalogue loading behind it. Start responds in the click's frame (2–17 ms, was 0.9–1.8 s): both windows close, and the try's page shows "Preparing…" with build progress in the terminal area. A failed create says why, with Back to setup.
  • A guide beside every try: what the tool is, the facts of this try, and first steps with Run and Copy. The build log shows how the image was made.
  • 42 tools to try: 28 coding agents and 14 AI tools, with 83 more listed as coming. Each is one YAML recipe aligned to Kit v3, checked against a JSON Schema and spec. New recipes are checked in CI on the m1b runner (make recipe-check). Grok Build 1.0.52, Factory Droid and Docker Agent report agent status (OSC 7501).
  • Keys from any major provider: OpenAI, Anthropic, Google and xAI, plus the OpenRouter and Vercel AI Gateway gateways, and Google Stitch. Keys can be read on use from 1Password, AWS Secrets Manager or a command. Each provider has its own default.
  • Accounts & keys redesigned (the owner's chosen mockup, 617.B9):
  • one card per provider, naming the tools its key serves, with the default chosen in place;
  • one status per key: Works, Not checked, Refused, Can't read, or No check;
  • failing keys first, with the provider's answer, the fix and the sandboxes affected;
  • By sandbox, with Change…;
  • Add a key for every provider, searchable by tool, or the exact doz account add line for 1Password, AWS, a command or a custom key;
  • lists capped at 960 px; works at phone width.
  • Fix: a key its provider refused showed a green "ok". It is now rejected on the page and in doz account ls. A source that can't be read is unavailable, not refused.
  • doz search says whether Dozer runs a tool and how, or why not yet.
  • Web ports: doz ports add and doz open, plus an Open button in the sandbox header. The page is on this Mac only.
  • Fix: dashboard icons no longer blink every few seconds.
  • Statistics: the dozer-telemetry Worker knows the new recipe ids (deployed on the owner's go).
  • Tests: make test 1071 tests, 0 failures, 4 skipped. The Accounts browser probe passed 29/29, and the Try-start latency probe passed.
