Creates are safe to retry: --request-id ID on doz workspace new, doz worker add, doz workspace adopt and doz permissions grant makes a repeated request answer the first answer again ("replayed": true) instead of doing it twice, and refuses the same id with other arguments (exit 3, request-id-reused, naming what differed); ids are kept for 24 hours and survive a daemon restart. The space editor is updated to 0.5.0 — the same editor rebuilt in layers, its live view much lighter to load.
