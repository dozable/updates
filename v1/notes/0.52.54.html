Where an agent runs is now a place of its own. A workspace's places — its own micro VM, fenced on this Mac, or as you — are declared in its space file (under x-dozable.places for now) and named by each agent's where:. A fenced place is a policy: the folders it sees (read-only or read-write), its network and its credentials; every session in it gets its own fence built from that policy, so two agents sharing a place never share a proxy, and an agent's own network can only narrow its place's. A micro VM's place sets its sandbox's network and folder. An unfenced place declares nothing and says so: "none: acts as you". An adopted sandbox is an external place. doz workspace plan and state --json list the places, and state shows each place's sessions and their fences. Permissions are always granted to an agent, never to a place.
