doz 0.51.13

The dashboard follows upgrades, offers "Restart dashboard", gives the right advice, and names its Mac (issue #470). On the owner's Mac a background dashboard started from Homebrew's 0.51.8 folder stayed 0.51.8 through two upgrades (a restart re-ran its own old program), while the doctor told them to stop the newer daemon.

  • It follows upgrades: doz ui starts from Homebrew's stable path and a restart starts the doz installed now. A dashboard whose program was replaced restarts itself when no page, terminal or operation is open.
  • "Restart dashboard" in the status card and the version banner when the dashboard is older than the installed doz — this Mac's own browser only (a device let in over the network or a proxy is refused and audited); the page reloads itself.
  • The right advice: no "Ctrl-C" for a background dashboard; doz doctor says the dashboard (or this doz) is the older one instead of telling you to stop a newer daemon; an update is never offered for the build already installed.
  • A name per Mac: the installable app is "Dozable – <this Mac's network name>" ("Doz <name>" in the Dock), and the window title says it, so each Mac installs as its own app. A copy installed before may need installing again to pick up the name.
  • Tests (re-run by the orchestrator): make test 2172 / 0; make test-cli-alwayson ALL PASS (a Homebrew-shaped prefix: started from opt, restarts itself on a new link, doz ui restart runs the newest); make test-cli-app ALL PASS; make css-lint; make audit; make docs-drift-check. Not seen yet: the button and the installed app's name in a browser.
