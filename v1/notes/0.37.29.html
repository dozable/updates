Dotfiles in every sandbox (issue #284; loop 627, step 25). Owner 2026-10-26: "go".

  • One setting, a pin per sandbox: sandbox.dotfiles takes a git repository's https URL (no user, token, ? or #) or a folder on the Mac that is a git repository; empty (the default) means none. A sandbox can have its own: --dotfiles URL|PATH|none on create/new/try/up, or dotfiles: in doz_project.yaml. The commit is recorded with the sandbox; changing the setting moves no sandbox, doz dotfiles NAME --update does.
  • Fetched on the Mac, never in the guest: the host fetches with the Mac's own git (no prompts) into <store>/dotfiles/, and the files go in as an archive on an exec's input. No guest network and no credential is involved, and it works in a VM a restarted host adopted.
  • Applied as the image's user, once per commit: at the first start and in a wake's background steps. The first of the usual install-script names runs (5-minute limit, its last lines in the boot log). With no script, the repository's top-level dot entries are linked into the home. An existing file is never overwritten, except a byte-identical copy of the stock /etc/skel file, which is kept beside as NAME.doz-stock. Dozable's own paths (.claude*, .codex, .pi, the agent launchers, every recipe's state folders) are never touched.
  • Trust like community recipes: the CLI asks once per repository and commit, at create and at --update. With no terminal it refuses (exit 5) and names doz dotfiles trust. The dashboard shows the repository, its commit and what will run in New Sandbox's review (https only; a Mac folder is never named by a page).
  • Surfaces: doz dotfiles NAME [--update] [--json], doz dotfiles trust, the Settings row, the sandbox Home's Folder facts, the agent's facts line, the plan, doctor, and Resources' cache:dotfiles. The manual's new page is 31, "Dotfiles". No image or bake key moved (RecipePinTests).
  • Tests: the full suite (1365, 0 failed); make test-cli-dotfiles all pass twice (55 checks, local scratch repositories only); the dashboard probe at 1440/390, light and dark.
