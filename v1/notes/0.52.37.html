Sandbox disks have their own command: doz image save SANDBOX NAME saves a sandbox's disk as an image a new sandbox can start from, and doz image ls and doz image rm list and remove saved disks with the other images (the dashboard says "saved disk" throughout). doz template create | ls | rm still works for this release and says where it moved — doz template is becoming workspace templates.
