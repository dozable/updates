The Agents / Bots screens.

  • Agents / Bots (#/bots) lists each bot: how it runs (unfenced ones marked "acts as you"), how it is reached, what it

manages or works in, and its key ("held by Dozable · fp …", never the key itself); "Show retired".

  • A bot's screen (#/bots/NAME) shows every workspace and room it is in and what it said last, with tabs to edit its

identity, how it runs, how it is reached, its instructions and its account. Changing a running bot's instructions, model or account is announced in its workspace's room; it applies from its next session.

  • From this Mac's own browser: make a bot, edit it, give it a new key, retire it, or turn a chat participant into a bot

(its old key stops working, and the page says so first). Another computer sees these screens read only.

  • A bot that runs on another machine gets its key in a terminal on this Mac (doz bot new … --to-file F); no key is

ever shown in a browser.

  • "Add an Agent / Bot…" in a room's menu invites a bot to that room.
  • doz bot show NAME --instructions prints a bot's instructions.
