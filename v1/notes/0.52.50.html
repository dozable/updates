The manual now travels with doz. Every release carries the manual for its own version (llms.txt, llms-full.txt and every page, inside the install), and doz docs shows it with no network and no daemon: doz docs says where it is and this version's online address, doz docs workspaces prints one page, and --json is for agents. doz help and the shipped skill now send people and agents to doz docs first, then to https://dozable.com/v/VERSION/llms.txt — never to a manual for another version. Getting started says that this Mac's Claude login expires, how doz account keepalive renews it, and that long unattended work wants a setup-token account. The manual's command lines are checked against the options each command really lists.
