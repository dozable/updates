doz 0.52.16

A dev menu bar app for trying changes, the dashboard allows inline styles, and a layout fix.

  • make app-dev builds "Dozable Dev": a copy of the menu bar app that runs beside the installed one, with a DEV badge

on its icon and "Dozable Dev" at the top of its menu. It has its own identity and settings, talks only to the doz, settings and store it was built for, and registers nothing with macOS (no Start at Login, no install). For people building Dozable; the released app is unchanged.

  • The dashboard's security policy now allows inline styles, so an editor can run in the page; scripts stay strict (no

inline script, no eval), and the page's own code stays free of inline styles.

  • Agents / Bots: a long command in a note no longer squeezes the note's text into a one-letter column.
