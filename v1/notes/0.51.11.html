doz 0.51.11

Chat's inbox delivery matches a Claude Code session by the name you gave it (issue #464, the 0.51.x fixes). A Claude Code session's name is free text the person sets — capitals and spaces included — but doz chat set … --session NAME accepted only the chat-name rule, so a session named like "OPS-PROJECTS on m1max" was refused (found by the peer on 0.51.10).

  • --session now takes any name of 1–100 characters, compared exactly as the session shows it; refused only: control characters, line breaks, direction-changing characters, /, and a space at either end. A refusal never echoes a control character. A participant's chat name keeps its own rule.
  • Tests: make test FILTER=ChatInbox 0 failures (new cases: capitals and spaces, accents, 100 characters accepted; empty, edge spaces, newline, NUL, an escape sequence, U+2028, a direction override, a path, 101 characters refused); CI on the PR.
