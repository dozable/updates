doz 0.60.3

The workspace editor in the dashboard can now be arranged and exported. Drag a part of the drawing to move it: Save keeps its place in the workspace file (this Mac's own browser only), and a part that can't move says why. Export downloads the workspace file as YAML, or the drawing as SVG or PNG — for anyone who may view the workspace, made in the browser from what that viewer can already see. The editor is updated to the drawing engine's 0.20.0.
