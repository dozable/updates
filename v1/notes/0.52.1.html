doz 0.52.1

Agent / Bot identities: a lasting identity you set up once and add to workspaces and rooms; there are no screens yet.

  • doz bot new / ls / show / set / retire / adopt / token.
  • Each bot has its own chat participant. Its token lives only in its keychain item, never in a command line, a record, a log or --json. A bot on another machine sees its token once.
  • Retiring a bot revokes its token. Its old messages keep its name, and the name stays reserved.
  • doz bot adopt turns an existing chat participant into a bot and replaces its token, saying so first.
  • doz chat remove, token and set on a bot point to the matching doz bot command.
