doz 0.52.3

Workers: one command brings an agent into a workspace with a task. There are no screens yet.

  • doz worker add W [NAME] --task "…". It is fenced on this Mac by default, with --isolation vm for a micro VM and --isolation unfenced only when named ("acts as you"). --from-bot BOT uses one of your bots; without it, the worker gets a throwaway chat identity.
  • A worker joins the workspace's main room and says it is up there with its task. Its chat token reaches it only as a placeholder.
  • doz worker ls W shows every agent with its place, isolation, controls, network and state.
  • doz worker end W NAME ends it and revokes its token; its messages keep its name.
  • --sandbox X runs a second worker inside a sandbox of the workspace.
  • A workspace must be started before workers are added; a bot runs in one live workspace at a time.
