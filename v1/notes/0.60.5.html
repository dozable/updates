doz 0.60.5

Bug fixes from the UX reset's audit of 0.60, and from the external tester. Canary only.

  • The New workspace wizard's "Discard this new workspace?" question now closes with the wizard; it no longer floats over the next page or the next wizard.
  • Add a worker: the "Where it runs" table's header no longer covers its first rows.
  • A template's agent that exits in error straight away is shown as waiting on you, not "asleep" with a Wake button, and the note after Create says so instead of "made and started".
  • A bot set to run in a sandbox is described as "sandbox", never "vm".
  • doz workspace new --path now suggests --folder, not --site.
  • Recipe tags (for example "Dozable" and "unpublished") read as separate words.
  • An expired agent login is reported in the room as needing to sign in again, not as the network refusing the site.
