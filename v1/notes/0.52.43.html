doz 0.52.43

Lifecycle fixes. A standing space file's plan now says what down keeps (it used to claim "nothing persisted"), and show / ls carry the workspace's lifetime. start after stop brings every agent back — workers too, no wake needed — and a stopped workspace reads "stopped", never "asleep" (the dashboard folds it with asleep and offers Wake). A sandbox's disk is never removed without a copy: at down and down --purge it is saved as an image first and named in the result; if the save fails nothing is removed. down's "Kept:" lists only the workspace's own things — your folders are listed as untouched, adopted agents as released — a dry run says "Down NAME — what it would do" instead of asking to finish, and the internal "(space-down)" label is gone.
