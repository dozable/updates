doz 0.52.10

The New workspace wizard.

  • New workspace (#/new-workspace, from Home, the sidebar, or a bot's screen) walks four steps: the work (the brief,

references, folders read-write or read-only — optional, with ~/doz-workspaces/NAME offered — and a starting preset; a doz_project.yaml in the main folder fills in its choices and is never written), who manages (a bot, a new one, or you), where it runs (the manager's isolation, new workers' isolation, the network preset), and the review.

  • The review says plainly what limits apply (none yet), lists what still needs setting up, live, and copies the same

workspace as doz commands. "Create, keep setting up" leaves it setting up; "Create and start" starts it, and stays disabled while anything is left to set up. An unfenced manager needs a confirmation and is labelled "acts as you".

  • Creating and starting a workspace works only in this Mac's own browser; another computer sees the command instead.
  • The workspace page and Home list what a setting-up workspace still needs, with a Start button.
  • doz workspace new … --dry-run shows the plan and what still needs setting up, writing nothing; new flags

--worker-isolation, --network, --new-folder and --start.
