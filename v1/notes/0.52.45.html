doz 0.52.45

A workspace's state now has one condition per layer beside ready: allocated (what the workspace holds — false after an archive, or after down for a runs space file or any --purge, with when and why), hot (each agent's session: starting, running, asleep, stopped or ended, and all / some / none running), run (the open run, or the last one, closed) and archived. doz workspace ls --json carries a short form on each row. phase stays, derived as before, for one release. The engineering page on the workspace model now describes bring-your-own-process — the run's primitives and opt-in permissions — as the plan for the unit of work. The dashboard walk waits for the redrawn list after a re-sort instead of a fixed pause.
