doz 0.52.47

Lessons from a run can now improve the next one. The work description is the brief plus addenda: an agent with description.propose (the new built-in reviewer role has it) proposes a lesson with doz workspace retro W --propose --addendum TEXT, and you decide it from the Ask Dozable posts in the workspace's room, or with doz workspace decide W PROPOSAL apply|decline. Nothing changes until it is decided. An agent you grant description.decide may decide (even its own), and one with description.edit adds an addendum directly with doz workspace edit W --addendum TEXT. A run with no goal starts from the brief and every addendum. A space file may request permissions for its agents under x-dozable.permissions; the plan shows them as requests, never grants. doz workspace proposals W lists them. Dozable's own Asks are posted under the chat server's reserved name, so no agent ever speaks for you.
