doz 0.52.48

Each run now has a journal: an append-only, ordered record that people and agents write and any process reads — the trace a bring-your-own-process workspace leaves. doz workspace journal W add KIND [TEXT] appends an entry (a note, a task, a claim, a review, a finding, an outcome, a lesson, or a kind of your own); Dozable sets its order, time and author, and never stores a token in it. Nothing is ever edited: a correction is a new entry of the same kind with --supersedes N, and readers show the correction. --attach FILE copies a file from the workspace's folders into the run and records its hash (--attach-ref hashes a large file in place). doz workspace journal W --follow streams entries, run boundaries and changes to the work description with one cursor to resume from, and doz workspace wait W --for journal.KIND returns as soon as such an entry exists. At finish the journal and its evidence go into the run's archive and never change again. Agents read the journal by default; writing, correcting another's entry and attaching are permissions (journal.write or journal.write:KIND, journal.supersede, evidence.attach), and the reviewer role carries them.
