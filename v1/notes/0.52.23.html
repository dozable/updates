doz 0.52.23

The workspace drawn as a picture.

  • A workspace made from a space file is drawn at the top of its page: the space on this Mac, what it owns and what sits

outside it, its agents and what they are doing — live, read-only, redrawn when something changes. Click it for a full-window view. A workspace made without a space file shows a plain band with the command that draws it.

  • Home and the sidebar show a small drawing of each such workspace; the others get a plain tile. Only pictures on screen

are drawn, each once, and the drawing code loads only when the first picture is needed.

  • The drawings follow the dashboard's light or dark theme and stay still. Another computer sees a workspace's drawing

only when chat is shared with it; otherwise the plain tile.

  • doz workspace ls --json says which workspaces a space file made.
