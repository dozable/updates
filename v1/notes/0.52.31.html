doz workspace state now answers for every workspace, however it was made — a workspace from the wizard or doz workspace new is no longer "not found" — with each agent's condition (running, asleep, stopped, crashed, not started) and whether the workspace is ready, and its --json carries kind and schema. Answering an Ask that is already answered, expired or not yours now exits 3 with its own error code (already-answered, invalid-phase, not-owned) instead of 1, and the dashboard says so the same way. In a guarded test run, stopping the daemon of a scratch store now also ends that store's sessions on this Mac, so a test never leaves a session behind.
