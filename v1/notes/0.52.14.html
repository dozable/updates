doz 0.52.14

Exports, chat members without a restart, and removing ended sessions.

  • Adding or removing chat participants no longer restarts the chat server: it takes the change live (and falls back to

a restart only when ports, webhooks or delivery change). doz chat add A B C --to-dir DIR and doz chat remove A B C change several at once. Bots and workspace workers benefit too.

  • doz chat read ROOM --since T --until T reads any span, past the old 500-message limit; `doz chat export ROOM --to

DIR` writes the messages, their attachments and a manifest with checksums. Every export is checked for keys and tokens, and any found is removed and named.

  • doz sessions @mac --transcripts S --export DIR now exports an unfenced session's own conversations as well as a

fenced one's — only that session's files, never a link — and works with the daemon stopped.

  • Sessions on this Mac that have ended or gone can be removed: a Remove button on each, "Remove all ended" on This Mac,

or doz sessions @mac --forget-ended (--dry-run to look first). Their conversations are copied back first; a session in a workspace, or one whose conversation could not be copied back, is kept with the reason. Removing works only in this Mac's own browser, and ending a session from another computer no longer forgets an ended one.
