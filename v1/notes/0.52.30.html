doz 0.52.30

Test hooks for the acceptance harness, in guarded test runs only: DOZ_TEST_STUB_AGENT=1 runs a deterministic stub agent wherever a workspace's manager or worker would start on this Mac (it joins its rooms, says it is up, acknowledges messages, and takes a few scripted commands; never a VM, never another token), and doz debug crash W/AGENT makes a stub exit as if it crashed. A workspace's log now records "NAME joined" when an agent joins its room and "NAME crashed: exit N" when one stops unexpectedly. The space editor is updated to 0.4.3, so the space page's text view again resizes with its window and shows no minimap.
