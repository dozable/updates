doz 0.52.32

One command now makes a workspace with its team: doz workspace new NAME --preset P --brief "…" --worker "TASK" (--brief - reads it from the input; --worker repeats, and the workers it declares start with the workspace at workspace start), and doz workspace create is the same command under the word people and agents reach for first. An unknown preset is refused, naming the ones there are; doz worker ls and doz workspace state show declared workers as not started; and doz create --help points to doz workspace new for making a workspace.
