doz 0.52.21

Asks in the chat server: a question that waits for a decision.

  • A member of a room can post an Ask: a question with options (or free text) for named deciders, by default the room's

people. The chat server decides who may answer: the people named, and a bot only while it holds the decider role. The first valid answer wins; the asker hears the outcome by webhook, by its poll or in its inbox. An unanswered Ask expires (after a day by default), also while the server was stopped. Each Ask gets a short number on this Mac, #N, never reused.

  • Only you give a bot the decider role: doz chat set NAME --role decider (--role none takes it away).

doz chat who shows it.

  • Limits, as settings: one open Ask per asker per room (chat.ask_max_open), a pause before the same question is asked

again after a decline (chat.ask_cooldown_seconds), the expiry (chat.ask_expiry_seconds). chat.asks false turns Asks off.

  • When a workspace finishes or its space goes down, the open Asks in its room expire at once: nothing is left waiting.
  • The chat server now follows the reference protocol's 0.17.0 release, where Asks are a standard part. Every room gets

the one-time "the protocol changed" note at the first start of this version.

  • Asking and answering from doz chat, the dashboard and the space diagram come in the next version.
