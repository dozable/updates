Space files gain doz: space/3.1, whose model-neutral keys are first-class: brief (a path, {text} or {file}, with refs), about with about.title, layout and network at the top; main on a folder; restart, network and external: { sandbox: NAME } on an agent. doz workspace doc writes 3.1. A space/3 file reads exactly as before; the old x-dozable spellings of these keys still read for this release, each with a note naming space/3.1, and a 3.1 key under doz: space/3 is refused with the version line to change. A workspace's lifetime stays under x-dozable and is never required — a top-level lifetime: in a 3.1 file is refused, because persistence is coming as lives: in space/3.2 (the accepted workspace model). A top-level title: is still read this once, with a note to write about.title.
