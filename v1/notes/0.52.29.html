doz 0.52.29

The exit-code contract is frozen: one table decides every doz command's exit status, and doz help exit-codes [--json] publishes it (0–9, 64 usage, 65 an invalid document or value, 75 partly done, 124 timed out, 125 doz itself failed around a program). Every JSON error now also carries its exit. An invalid value or document now exits 65 instead of 64 (unknown commands and flags stay 64); a space file's errors exit 65 instead of 2; a workspace up or down that is partly done exits 75 and its --json says what is done, what remains and the command that retries the rest; a bot confirmation with no terminal exits 5; an ambiguous restore-point name exits 2. Some JSON error codes became more precise (plan-changed, file-changed, needs-confirmation, usage) with the same exits as before.
