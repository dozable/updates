doz 0.37.2

Dozable moves to its own GitHub organisation, and the update feed to updates.dozable.com (issue #277; loop 627, step 4). Owner 2026-10-20: "yes go with step 4".

  • The source is at github.com/dozable/dozable, a fresh public repository: the history was rewritten so every commit carries the noreply address (four merge commits carried the personal one), the 24 releases re-created with the same files, the CI Macs registered to it, and every outside contributor's pull request waits for approval before it runs on them. The feed's entries and the Homebrew formulas download from it. The old dozer-sandbox/dozer-sandbox is deleted on the owner's word; the dozer-sandbox organisation stays, empty, so nobody can take its names.
  • The update feed is https://updates.dozable.com/v1/feed.json. Every doz before 0.37.2 asks updates.dozersandbox.com, which is now a permanent redirect there (a released 0.36.5 finds 0.37.1 through it). The website's version line and the privacy page name the new host.
  • Everything else moved to the dozable organisation: the website, the feed, the tap (in 0.36.1), the newsletter and the closed package's repository (dozable-cloud-prelaunch). dozable.com is verified there.
  • The official builds' closed package is DozableCloud, and the audit's old-name check covers it. Its queue of unsent statistics now lives in doz's settings folder (~/.config/doz): 0.37.0 and 0.37.1 official builds kept writing the old ~/.config/dozer-sandbox, re-creating the folder the upgrade notes say to delete.
  • The workspace's checkout is repo/app/dozable.
  • Tests: full make test 1128, 0 failures (from a clean build at the new path); make test-updates 59/59 against the new host; docs-drift-check and make audit green; the closed package 22/22 and an official-flavour build reporting "official": true.
