doz 0.60.4

Fixes from a first-time user's run of 0.60.2. A fenced agent — the solo template's included — can now read its own start note and the chat skill files it names (exactly those files, nothing wider), so a new workspace's agent says it is up instead of sitting idle. An allowed HTTPS site now works inside the fence: its certificate bundle holds every root macOS trusts, so curl, git, node and pip succeed (Apple's own /usr/bin/python3 still ignores the bundle). doz workspace new --template takes --brief, --dry-run and --json. doz config set, doctor and onboard say which settings file they use when you point doz at a second store, and the manual lists the files written outside a store. Smaller: a template's agent session is named NAME-agent, finish speaks of finishing, doz sessions ls --json works with no name, and onboard --no-base no longer says a base is ready.
