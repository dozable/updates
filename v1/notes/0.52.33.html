Agents now find workspaces first: doz --help opens with a short "Start here" block (doz workspace new, doz workspace state, doz worker add) on its first screen, and Dozable ships a skill for coding agents that drive it — doz skill show doz prints it and --json gives its path — covering making a workspace in one command, reading its state, adding a helper, the exit codes and the error JSON. The manual's "Letting another agent drive" page gains a Workspaces section.
