Sessions on this Mac (@mac) (issue #392). Owner 2026-11-12: "get started on the native holder", "yes, bypass is confirmed", then "ship it to canary then promote". For work a Linux sandbox cannot do — Swift, Xcode, signing, notarisation — Dozable now holds terminal sessions on the Mac itself, the way it holds them in a sandbox.

  • doz run @mac -d --session S --workdir DIR -- CMD starts a program on this Mac, held by Dozable's session holder (deckhold, now built for macOS and shipped beside doz, signed and notarised). doz sessions @mac lists them with their status (and, in --json, the folder, the command, when it started); doz sessions send / screen / wait / end / restart and doz attach @mac S (with the Ctrl-] menu) work on them as on a sandbox's. Restarting Claude Code continues its conversation (--continue) unless you say --fresh.
  • No isolation, said plainly: a session on this Mac runs as you — your files, Keychain and network, no proxy and no key placeholders — and doz run, doz sessions @mac and doz ls say so. Dozable never adds a permission bypass; a session whose own command asks for one (claude --dangerously-skip-permissions) is marked "permissions bypassed".
  • A clean environment: a session gets an allowlist (HOME, USER, SHELL, LANG, SSH_AUTH_SOCK, TERM, your login shell's PATH, and your own -e NAME=VALUE) — nothing of the process that started it, so a session opened from inside Claude Code no longer inherits its markers (which turned transcript saving off).
  • They outlive doz: sessions keep running through doz host stop, a host crash and an upgrade, and the next host adopts them (same process); after a logout or reboot they show as gone, and doz sessions restart @mac S starts them again from their record. Every other command refuses @mac with one plain line.
  • doz sessions wait SANDBOX|@mac SESSION --until idle|done|blocked|error waits for a session's status, or a comma list of them ("has it stopped working?"); exit 124 on --timeout.
  • Fixes from the first real use: doz sessions send --text … --enter now submits a long line (the text and the Enter used to arrive in one burst, which a terminal program took as a paste); doz sessions SANDBOX --json carries each session's full argv (the stored command is cut at 255 characters).
  • Tests: make test-cli-host (89 checks, twice), make test-cli-sessionsend (VM, twice), make deckhold-mac-check (status 211, grid 36, snapshot 49,973 cases, the Mac smoke), new unit suites, make test 1561 / 0, the audit and the docs checks; the agent-relay skill ran a full team of Claude Code sessions on @mac (typed input, screen reads, status, Remote Control, refresh with --continue). Still to come: host sessions in the dashboard and doz serve.
