doz 0.52.56

An agent in a workspace is now an identity with sessions. The identity is who it is — name, role, kind, its token, its memory; a session is one run of its program in a place. A worker you name (doz worker add W NAME) lasts with the workspace: doz worker end stops its session and keeps it in the room with its memory, and adding it again brings back the same agent. A worker added only with a task belongs to the run and goes when it ends. A fenced agent's memory is kept between its sessions whatever kind of workspace it is in, a switch between fenced and unfenced keeps it with a warning, and doz worker reset W NAME clears it. Each start gives an agent a new chat token (unless you took its token yourself with doz chat token, which then stays yours), and down revokes them. down --purge now works for every workspace: it copies each lasting agent's memory into the workspace's archive, checks the copy, and only then removes it. doz workspace state --json lists identities (with when each token was issued, never the token) and sessions; worker ls shows each worker's lifetime and the agents kept with no session. Records written by earlier versions are read and rewritten in the new form.
