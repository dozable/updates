doz 0.52.46

A unit of work now has its own verb: doz workspace run W [GOAL] opens a run with its goal (the brief when none is given), where it came from (--source), the run it follows (--follows), who opened it and the work description's revision it read; it posts the goal in the room and starts the agents (--no-start to not). One run at a time: while one is open, run is refused (exit 3, run-open) and names finish. reopen is now the old name of run. up still opens a run when none is open, and up --no-run opens none. runs --json lists each run's goal, source, revision, who opened it and how long it took. An agent needs the new permissions run.open and run.finish to open or finish runs; an existing workspace.finish grant still counts for both in this release.
