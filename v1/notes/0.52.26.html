doz 0.52.26

Chat in its own window; chat finds free ports itself.

  • A room can be popped out into its own window — from the Chat page or a workspace's Room tab. The window is a light page

of its own (/chat#/ROOM) that loads only chat's code: live, answering Asks and turning chat on, surviving a reload or a bookmark, one window per room (clicking again brings it forward). Reading in the window clears the dashboard's unread mark. Another computer gets the same chat it would in the dashboard. Up to about four windows at once, with the dashboard on a page other than Chat.

  • The space editor's "Open in a new window" now opens one (it did nothing before), one window per workspace.
  • When chat's default ports are taken by another program (another Dozable on the same Mac, say) and you have not set

them yourself, chat picks free ports, saves them in your settings and says so once; a port you set yourself is never changed.
