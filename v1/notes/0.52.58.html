doz 0.52.58

The hotfix after 0.52.55 reached stable. A store that declined this Mac's Claude Code login (doz onboard --claude-account none, or the new doz account default none --decline-mac) never uses it again: agents fenced on this Mac take the store's own default account, or none, and a session that names mac is refused — before, a fenced worker could still fall back to the Mac's login. The remotion-video preset (and any workspace on the standard network) now starts its micro VM workers: the workspace's standard level is the VM's agent network.
