doz 0.52.6

The machine picker: "Dozable · <this Mac> ▾" at the top left opens Your Macs. (0.52.5 was tagged but never released: its helper build failed; this release carries the picker and the fix.)

  • doz ui macs add NAME ADDRESS, ls, rm and check keep a list of your other Macs' dashboard addresses. Nothing

is discovered automatically, and a sign-in link given as an address is refused.

  • Picking a Mac opens its dashboard in a new tab, where that Mac's own sign-in applies. Nothing is passed between

Macs, and this Mac never contacts the other.

  • The menu shows when each Mac was last seen answering (checked when you add it, or with doz ui macs check).
  • This Mac › Your Macs lists them with the commands to add and remove.
  • Fixed: the build an app carries inside its bundle compiles again.
