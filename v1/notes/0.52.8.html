doz 0.52.8

The Agents tab, each agent's screen, and putting loose agents in a workspace.

  • A workspace's Agents tab (#/w/NAME/agents) lists every agent in one table: where it runs, its isolation (unfenced

ones marked "acts as you"), its state, its task, its controls, and who started it and when.

  • Opening an agent (#/w/NAME/agent/AGENT) shows its sandbox or session page inside the workspace, with what it does

there; its old address still works and says which workspace it is in.

  • "Put in a workspace…" on a loose sandbox or session files it into an existing workspace or a new one;

"Take out of the workspace" makes it loose again. It keeps running either way. Filing an agent that is already running marks the workspace started, and nothing is posted. Only this Mac's own browser can do this.

  • doz workspace ls --json and show --json gain which agents' places a workspace holds, and who started each agent.
