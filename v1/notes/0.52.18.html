doz 0.52.18

Space files: their format, and the plan of what up will do.

  • doz workspace plan -f FILE (also doz space plan) reads a space file — a workspace written as a file in git —

resolves its extends: defaults, override file and ${VAR} values, checks it, and prints what bringing it up would do: every agent, room, folder and sandbox, whether each is yours already or made for the run, what is kept between runs, and every risky setting (an unfenced agent, bypass, open network, grants requested, no archive) with the file and line it came from. Problems are reported with file, line and a hint. It changes nothing and starts nothing.

  • doz workspace config FILE prints the merged file, each value with where it came from.
  • Bringing a space up and taking it down come in the next version.
