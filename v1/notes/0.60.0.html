Dozable 0.60: the repositioned product, as a version of its own. Dozable runs teams of AI coding agents on your Mac: a workspace holds the agents, their chat room, the folders they work in and a brief; the work is done one unit at a time, each recorded in a journal, and the lessons you approve carry into the next; each agent runs where you choose — its own micro VM, fenced on your Mac, or as you. This is the 0.52 line's work (0.52.0 to 0.52.58) under a new minor number, with these fixes on top (built as 0.52.59, which was never released): a workspace's Home tab now draws every space file the editor and doz workspace plan accept (places, feeds and permissions showed an error); a brief's references may be relative to the space file's folder or start with ~/, and up accepts what plan does; a space file's top-level network: is now the workspace's network — every agent it starts and every place with no network of its own gets it (a file with none stays locked); and in a store that declined this Mac's Claude login, doz config show and doz run @mac --dry-run show the account a fenced session will actually use.
