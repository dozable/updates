doz 0.52.0

Workspaces arrive, as records and commands; there are no screens yet. A workspace is an environment set up for getting work done: its agents, its rooms, the brief that says what the work is for, and any folders it works on.

  • doz workspace new / ls / show / adopt / release / edit / log / rename.
  • Existing sandboxes and @mac sessions are listed as loose agents until you adopt them; adopting never changes their

own records.

  • With chat on, a new workspace gets a main room named after it. Nothing is posted there until the workspace starts.
  • doz ls --json and doz sessions --json gain a workspace field.
  • ls, show and log work without starting the daemon.
  • Also fixed: the startup test suite still called doz host.
