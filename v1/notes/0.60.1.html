doz 0.60.1

Every workspace is drawn now, not only one made from a space file: a workspace made with the dashboard's wizard or doz workspace new is drawn from its document (the one doz workspace doc writes), on its Home tab and in every thumbnail, with its live state. A manager or worker that runs unfenced and is reached through its Claude Code inbox now receives messages: it was started without a session name, so the chat server never found it — it read "not running", messages were not delivered and dozchat protocol was refused (after updating, stop and start the workspace, or sleep and wake it). Every manager and worker is now told to read the chat skills doz ships, by path (nothing is written into your agent configuration), and a workspace's brief is posted once its manager has started, so an inbox-reached manager receives it. An empty status box no longer shows above a room.
