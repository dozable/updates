doz 0.60.8

The menu bar app lists your workspaces. Canary only.

  • Dozable's menu bar menu has a Workspaces section: each workspace with its state, the ones waiting on you first. Each has Open, which shows its page in the dashboard, and Sleep or Wake, whichever fits. The first ten are listed, then All Workspaces…, which opens the Workspaces page.
  • doz ui open NAME opens a workspace's page in the dashboard (--workspaces for the Workspaces page), starting the dashboard in the background when it is not running.
  • The section appears with doz 0.60.8 or later; with an older doz the menu is as before.
