doz 0.50.4

The doz daemon stays running (issue #423; step 8a of the session access program, #405 — the first of four releases for the always-on daemon and kept sessions). Owner, 2026-11-16: "yes always on (a new setting - default on). change timeout default to 0 (never times out)".

  • daemon.always_on, on by default: the daemon no longer exits when nothing runs. It is read by the running daemon, so doz config set daemon.always_on off takes effect in about a second.
  • daemon.idle_timeout_minutes now defaults to 0 (never) and is used only when always-on is off. So for the old behaviour set BOTH: doz config set daemon.always_on off and doz config set daemon.idle_timeout_minutes 5. A settings file that already says idle_timeout_minutes = 5 no longer applies while always-on is on; doz config show says so.
  • A daemon that never idles out still picks up a new build: when its program is replaced (an upgrade) and nothing is running, it starts a new daemon and exits — no command needed. The new one is started from a stable path (a Homebrew keg's opt link), so a brew cleanup that removed the old keg does not matter. From 0.50.3 the old daemon cannot do this: it exits after the upgrade and the next command starts 0.50.4.
  • A daemon started where the login keychain is locked (over ssh) is never always on: it exits after at most 5 idle minutes, so a later command from the desktop gets one that can read the keychain.
  • Shown: doz daemon status (and --json alwaysOn) and doz doctor.
  • Not in this release: starting at login (the next release — nothing is written to ~/Library/LaunchAgents here), the login keep-alive, kept sessions.
  • Also changed: with fenced sessions running, a newer recipe catalogue now hands the daemon over to a new one (before, it shut down and left their proxies unserved until the next command); a --foreground daemon never restarts in place, it exits.
  • Tests: make test 1777 / 0; make test-vm-upgrade passes with a new part (0.50.3's idle daemon, this build installed by rename, then this build's always-on daemon restarting in place in about 4 s, one daemon throughout); the new make test-cli-alwayson, make test-cli-host, make test-cli-fence, make test-cli-keychainlocked pass; make test-cli 935 pass with the 2 failures that predate this release (backlog 683.B4, 689.B2).
