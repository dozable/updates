doz 0.50.7

A menu bar app for the doz daemon: Dozable.app (issue #428; step 9a of the session access program, #405). The owner's scope for the first app: the daemon's state, Start, Stop, Restart, open the dashboard — no chat in it. Starting at login from the app is the next release.

  • doz app install puts Dozable.app in Applications (your own Applications folder when that one is not writable); doz app status, doz app uninstall; doz uninstall removes it too. The app ships inside the doz release — nothing appears on a Mac until you run the install. It is checked before it is copied (signature, Dozable's team, the same version as doz) and swapped in by rename.
  • The menu: the daemon's state in one line — running with its version, stopped, stopped on purpose, started from ssh (it cannot read your Keychain; Restart from the menu fixes that), running an older build, starting or stopping; then Start Daemon, Stop Daemon… (it asks first when sandboxes are running), Restart Daemon, Open Dashboard, and Quit Dozable Menu, which never stops the daemon. When doz is missing or older than 0.50.5 the menu says so and offers what still works. When the copy inside doz is newer, it offers "Update menu bar app".
  • The icon is a placeholder glyph that shows the state: filled, outline, with a dot, dashed.
  • How it is built: the app only ever runs the doz command (--json, by absolute path, no shell); it does not talk to the daemon itself, so it keeps working across doz upgrades. It never sees a dashboard link. Its periodic status checks are not counted in anonymous usage statistics.
  • The release now builds, signs, notarises and staples the app with doz, and checks it before notarisation; the smaller helper release does not carry it.
  • NOT verified by any test, and to be looked at by a person: the menu on screen, the icon in light and dark, the Stop question, Open Dashboard arriving signed in, the first open with no Gatekeeper warning.
  • Tests: make test 1877 / 0 (the status model from real fixtures, the menu's state table, the command runner, the install); the new make test-cli-app (36 rows: the model with doz missing, start from the app with the daemon outside its process tree, the dashboard opened with no link anywhere, doz replaced under the app, install and uninstall into a scratch folder, a tampered bundle refused); make test-updates (the update swap carries the app). make test-cli shows only the 2 failures that predate this release.
