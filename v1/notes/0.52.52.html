doz 0.52.52

Agents now keep the journal themselves. Inside its sandbox or session an agent has no doz, so it reaches Dozable through dozchat with its own token: dozchat journal, dozchat journal add, dozchat journal wait, dozchat propose --addendum, dozchat proposal decide and dozchat addendum. Each is decided by the same permissions as doz … --as, and a refusal names the permission missing. Every unit of work now opens with the brief, then "Lessons to apply" (every lesson you accepted), then its own goal when it has one, so a lesson is never lost because a run had a goal. An agent you adopt into a workspace gets its own place in the room and its own token, handed to every session Dozable starts or restarts in that sandbox (never written to the sandbox itself; --no-token keeps it off chat; release revokes it), and every session in a workspace reaches its own store's chat server.
