doz 0.52.28

A history of this Mac, kept for the timeline to come.

  • Dozable now keeps what happened, in one searchable store on this Mac: the daemon's events, each sandbox's connections

(the hosts it reached — hidden unless you ask for them, kept a week by default), each running sandbox's CPU, memory and disk once a minute, and when a key was used — alongside the actions, sessions, workspace and permission logs, runs and chat it already kept. Nothing leaves the Mac; no message text, question, command, path or key value is ever stored.

  • doz timeline catalog | query | tail read it (the dashboard's timeline comes next). Retention is yours to set per

source (timeline.* settings: days of single events, then minute, hour and day totals); doz timeline prune --dry-run shows what would go, doz timeline rebuild rebuilds the store.

  • Retention applies to the new records and the searchable store only: the history Dozable already kept is left as it

is for now.

  • daemon.mac_name names this Mac in the history ("this Mac" by default).
