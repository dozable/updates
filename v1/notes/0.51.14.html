doz 0.51.14

doz ui publish tailscale: the dashboard on your tailnet at its own https address (issue #474). On m1max this was set up by hand on 18 November (a second Tailscale node, five settings), and it would not have survived a reboot.

  • Dozable's own Tailscale node: Homebrew's tailscaled in userspace mode, its state in the store, kept running by a per-user LaunchAgent. The Mac's own Tailscale and its tailscale command are left alone. Named dozable-<this Mac's name> by default (--name to choose); the first run shows Tailscale's sign-in link and waits for it; --adopt-state takes over a node started by hand, keeping its name and address.
  • Serving: https on 443 with Tailscale's certificate; port 80 answers with a redirect to the https address (the running dashboard answers it on a socket in the store; the target comes from the published address, never the request).
  • One step: the fixed port, this-Mac-only listening, the trusted proxy and the public address are set, and the dashboard restarts. Chat on other devices stays as serve.chat says.
  • It comes back: while published, the daemon (started at login) starts the dashboard when it is not running, so the address answers after a reboot or a crash; never after you ran doz ui stop (or Ctrl-C), until you start it again.
  • doz ui publish status, doz ui unpublish tailscale [--logout] (settings back to this Mac only; --logout also removes the node), and doz doctor rows: the node, its sign-in, 443 pointing at the dashboard's current port, the port-80 redirect, the dashboard kept running.
  • Tests (re-run by the orchestrator): make test-cli-alwayson ALL PASS (a fake tailscale and launchctl: publish, idempotent re-run, status, a port mismatch caught, the dashboard brought back after a kill and not after ui stop, unpublish, a sign-in never approved); the publish unit suites; make audit; make docs-drift-check. A live probe on m1max's node showed Tailscale's port 80 reaching a unix socket (308, path and query kept). Not yet run for real: the full command against the real Tailscale and launchd — done on m1max after release.
