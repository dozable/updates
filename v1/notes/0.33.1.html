doz 0.33.1

The agent can write your workspace again.

Since 0.30, an agent in a sandbox (Claude Code, pi, Codex) could read a shared workspace folder but not change it, and git refused the folder ("dubious ownership"). 0.33.1 fixes this.

After upgrading:

  • A sandbox that is shut down gets the fix at its next start.
  • For one that is running, asleep or hibernated, run doz shutdown NAME and then doz start NAME.

Your rules in .dozignore and .dozreadonly work as before.

Upgrade with doz upgrade.
